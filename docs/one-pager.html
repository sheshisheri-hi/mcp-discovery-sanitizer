One bad MCP tool server.
Every coworker’s AI agent gets the poison.

Discovery text (instructions, tools/list) gets cached and pasted into the system prompt. This CPU-only gate decides allow / strip / block before that happens. No LLM. No GPU.

The problem

Server-controlled text lands in the system prompt with no bound and no isolation.

The amplifier

cacheScope: public can fan one bad list across every agent behind a gateway.

The gate

Sanitize discovery first. Readable reasons + a SHA-256 so swaps show up in a diff.

Before → after

Before

  • Poisoned discovery returns
  • Public cache reuses it
  • Every agent eats it
→

After

  • Sanitizer sits in front
  • Public cache from strangers refused
  • Only a clean verdict reaches the prompt
