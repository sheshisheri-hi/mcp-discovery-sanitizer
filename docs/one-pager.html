AI security · MCP · weekend sample

One poisoned MCP server.
Every teammate’s agent.

Agents fold discovery (instructions, tools/list) into the system prompt. Mark it cacheScope: public and a shared gateway can fan the poison out. This page is the fix in one screen: a CPU-only gate that decides allow / strip / block first.

The problem

Server-controlled text lands in the system prompt with no bound, no isolation, and sometimes a public cache bit nobody verifies.

The amplifier

cacheScope: public means “serve across auth contexts.” One bad list becomes a company-wide injection.

The gate

Sanitize discovery before the agent trusts it. No LLM. No GPU. Readable reasons + a SHA-256 for diffs.

Before → after

Before

  • Server returns poisoned discovery
  • Public cache reuses it
  • Every agent behind the gateway eats it
→

After

  • Sanitizer sits in front of discovery
  • Public cache from strangers refused
  • Only allow / strip / block reaches the prompt
allow strip block

What it checks

Instructions

Length bounds + obvious-injection tripwire. Leftovers can be wrapped as untrusted.

Public cache

Default-deny cacheScope: public unless the server is on your trust list.

Tool text

Names and descriptions treated as hostile input, not trusted schema docs.
